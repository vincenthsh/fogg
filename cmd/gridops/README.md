# GridOps

This CLI interacts with the Grid API to manage Terraform states and dependencies based on marker files generated by fogg.

It will create states, manage dependencies between states, and resolve the terraform state outputs actually consumed.

## Commands

### `gridops auth`

Authenticate with Grid API and output access credentials. This command is useful for integrating with tools like Atlantis that need to authenticate programmatically.

#### Flags

- `--service-account <path>`: Path to service account JSON file containing `client_id` and `client_secret`
- `--token`: Output only the access token (useful for Atlantis integration)
- `--server <url>`: Grid API base URL (or use `GRID_API_URL` environment variable)
- `--client-id <id>`: Grid service account client ID (or use `GRID_CLIENT_ID` environment variable)
- `--client-secret <secret>`: Grid service account client secret (or use `GRID_CLIENT_SECRET` environment variable)

#### Service Account JSON Format

```json
{
  "client_id": "your-client-id",
  "client_secret": "your-client-secret"
}
```

#### Atlantis Integration Example

To integrate with Atlantis, you can use the auth command to dynamically fetch access tokens for Terraform HTTP backend authentication:

```yaml
workflows:
  grid:
    plan:
      steps:
        - env:
            name: TF_HTTP_USERNAME
            value: 'gridops'
        - env:
            name: TF_HTTP_PASSWORD
            command: 'gridops auth --service-account /etc/grid/sa.json --token'
        - init
        - plan

    apply:
      steps:
        - env:
            name: TF_HTTP_USERNAME
            value: 'gridops'
        - env:
            name: TF_HTTP_PASSWORD
            command: 'gridops auth --service-account /etc/grid/sa.json --token'
        - apply
```

The `--token` flag ensures only the JWT token is printed to stdout, making it easy to capture in environment variables.

### `gridops sync`

Synchronize local marker files with the Grid API.

### `gridops doctor`

Diagnose issues with marker files and Grid API connectivity.
